ℹ️ About SpamGuard

SpamGuard is a Machine Learning based web application designed to identify whether a text message is Spam or Not Spam.

🤖 Machine Learning

The system uses TF-IDF for text feature extraction and Multinomial Naive Bayes for classification.

⚙️ How It Works

User Message → Text Processing → ML Model → Spam / Not Spam → Confidence
